## 完成顺序与验收门

1. 操作与存档回归
   - 逐项验证主孢子、核心菜单、右键取消、三类方形区域、RTS 选兵和指令。
   - 普通档与开发者档必须隔离；读取旧档必须显示进度且不能冻结窗口。

2. 视觉尺度与辨识度
   - 近景能看清角色结构，中景保留职责轮廓，远景只保留稳定的粗像素识别点。
   - 主基地与兵营等大；体外孢子明显小于核心；选择圈和血条不得改变单位的实际比例。

3. 兵营、食性与自动化闭环
   - 基础采集兵种始终可用；细菌、真菌特攻单位只出现在对应食性路径。
   - 手动指令优先于自动任务；卸货、修复、补员后恢复保存的兵营任务。
   - 采集细菌时只承受明确显示的防御毒素或反击伤害，不能把普通采集误判成无来源扣血。

4. 第一章数值与目标
   - 分别检查约 20 分钟、2 小时、24 小时和 72 小时的玩家进度。
   - 已完成：48 小时离线上限、受控长时段产速/有限资源/预付 DNA 核验与密集异步载入回归；详见 [离线结算记录](OFFLINE_PROGRESS_48H.zh-CN.md)。
   - 已完成正常地图前 20 分钟的脚本可达性与收支验证：不用开发者补资源，约 6 分 39 秒获得首份 DNA，13 分 20 秒解锁食性，14 分 05 秒产出首个游猎孢子。详见 [开局验证](CHAPTER1_OPENING_PROGRESS.zh-CN.md)；这不是玩家平均耗时，也未验证返巢收益、正常路线 2/24/72 小时或完整章节平衡。
   - DNA、核心、兵营与单位成本必须形成可理解的慢节奏成长，不允许并行核心无限倍增产出。
   - 每个长期目标给出不同奖励；章节完成报告不强制结束当前存档。

5. 生态、性能与可靠性
   - 覆盖 420 个细菌、64 个体外单位、多核心、敌方菌丝、守卫、毒素区和 60× 加速。
   - 核心死亡、断联菌丝衰败、其他核心救援、失败与恢复路径必须可复现。

6. 发布门
   - 全量自动测试、实际浏览器测试和 Windows EXE 测试全部通过。
   - 七语言仓库介绍、游戏界面、教程、版权说明与版本号一致。
   - 每个测试版本都保留服务器路径、提交号、构建时间和 SHA-256；最终 Windows ZIP 解压后可直接运行。
