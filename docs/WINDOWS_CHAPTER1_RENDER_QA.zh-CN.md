# 第一章 Windows 实际渲染核验

日期：2026-09-13。此记录描述真实 Windows 图形输出，不把截图夹具当作普通模式经济、战斗或人工操作证据。

## 方法与范围

- 使用项目对应的 Godot 4.7 Windows 运行时与独立 PCK，在隔离的临时项目中将入口替换为可重复的渲染夹具；正式项目入口不变。
- 本机实际设备为 Intel Iris Xe Graphics，OpenGL 3.3 Compatibility，驱动 32.0.101.6737；不是 headless 空渲染。
- 每次测试使用独立 APPDATA / LOCALAPPDATA，禁止覆盖玩家存档或语言设置。进程隐藏启动，45 秒超时只终止本次测试进程。
- 33 张真实画面覆盖首次语言选择、七语主菜单、主孢子、主核心与兵营状态、七语生产菜单、低生物量提示、七语指引首页、六个指引主题，以及 640×360 缩小窗口。
- 标准检查尺寸是 1280×720。640×360 截图是现有 canvas_items 缩放行为，不能声称它等同于独立的 640 像素响应式布局或具有相同文字可读性。

## 已确认与修复

- 标准尺寸下检查的菜单、指引图片、核心危险卡和兵营生产内容正常绘制；主核心和兵营保持同一世界尺寸，缩放时采用已有 LOD。
- 实际截图暴露兵种筛选条硬编码中文缩写。现已补齐七语 77 个短标签，并复核英语、俄语实际画面没有溢出；短标签及宽度另有自动测试。
- 原安装包退出时出现一项 GPU 纹理泄漏：8520 字节，并伴随 RenderingServer 已销毁的纹理清理错误。主场景退出时提前解除自定义鼠标贴图后，同一真实渲染测试退出码为 0，标准错误输出为空。
- 上述证据说明本次退出纹理问题已修复，不能据此推断用户历史上所有访问冲突的原因相同。

## 验收边界

- computer-use 原生窗口操作工具因本机沙盒初始化故障不可用；没有绕过工具限制注入鼠标或键盘，也没有完成真人式完整试玩。
- 画面夹具调用游戏场景和绘制接口，不证明鼠标手感、音量舒适度或新玩家理解程度。自动交互、数值、存档和战斗证据由相应回归测试与自然路线日志提供。
- 渲染夹具使用 Dummy 音频以免后台截帧反复播放音效。最终安装包另以真实 OpenGL 和默认 WASAPI 运行 180 帧：双声道、48000 Hz，背景音资源成功加载，退出码 0，错误输出为空。此项验证初始化与资源加载，不等同于听感验收。
- Windows 分离包通过 ZIP 精确结构检查、30 帧相邻 PCK 启动检查和 SHA-256 校验。运行检查现显式隔离 APPDATA / LOCALAPPDATA，并在成功或失败后恢复环境，避免打包测试读写玩家设置。
