# 第一章：有限资源采集—返巢—再出发回归

## 本轮结论

新增 `tests/chapter1_economy_cycle_smoke.gd`，验证一个正常付费生产的游猎孢子在有限采区内，能够自然完成采集、满载返巢、卸货和再次出发；资源不足满载时，尾批也能返巢。当前单项测试通过，没有发现需要修改生产逻辑的阻断问题。

这是**预建兵营的机制夹具**，不是普通新局成长速度或真人体验测试。它补充 `chapter1_opening_progression_smoke.gd` 的真实开局路线，也补充已有 `harvest_zone_smoke.gd` 对状态转换的覆盖：本测试不把单位传送到资源或基地，不直接填充货舱，不直接改写运输状态。

## 夹具与控制条件

- 开发者模式关闭；保留真实新局的 220.000 有机营养、24.000 矿物离子和 0 DNA，不赠送资源或领取目标奖励。
- 预建一个原点兵营，移除其他核心、菌丝、细菌和敌方实体，以隔离运输机制。兵营建造与前置科技的成本不在本测试中，因此不能据此推断正常开局的兵营时间。
- 调用实际生产接口，支付 8.000 有机营养和 0.250 矿物离子，经过实际队列的 30 秒生产 1 个初始游猎孢子。
- 使用一个 140 × 140 世界坐标单位的正方形采区。区内三个有机资源点分别为 0.600、3.400、4.250，总计 8.250；另有 2.125 矿物作为不可采类型对照，区外另放 5.000 有机营养作为范围对照。
- 通过现有核心的真实探索接口揭示附近区域，不直接注入探索状态。所有资源都放在核心被动吸收范围外，且没有菌丝吸收器。
- 以 0.25 秒固定步长调用真实 `_process`，游戏速度为 1；加速的是测试执行而非游戏数值。没有用离线收益、跳过生产、无限资源或瞬移完成运输。

## 路线与观测结果

以下为当前版本的一次确定性脚本运行；时间从生产排队开始累计，属于模拟游戏时间，不是人工游玩耗时。测试限制总路线在 600 秒内完成，不将下表的每个时间点硬编码成必须相等的断言。

| 模拟时间 | 事件 | 实际入账 |
| --- | --- | --- |
| 00:30.00 | 游猎孢子正常生产完成，分配采区 | — |
| 01:54.25 | 首次满载自然返巢卸货 | 3.000 有机营养 |
| 02:16.50 | 插入手动移动与 20 秒原地待命后，重新指定原采区 | — |
| 03:41.75 | 第二次满载自然返巢卸货 | 3.000 有机营养 |
| 03:46.00 | 没有追加命令，自动再次前往区内资源 | — |
| 04:48.75 | 资源耗尽，不足满载的尾批自然返巢 | 2.250 有机营养 |
| 此后 60 秒 | 保留采区指令，继续运行 | 没有重复入账或额外收入 |

最终共运回 8.250 有机营养；余额为 `220.000 − 8.000 + 8.250 = 220.250` 有机营养、`24.000 − 0.250 = 23.750` 矿物离子。区内矿物仍为 2.125，区外有机营养仍为 5.000。DNA 为 0，未领取任何目标奖励，单位总数和累计生产数都为 1。

单项执行墙钟约 1.6 秒；该数字仅供回归运行参考，不是帧率或大规模单位性能结论。

## 核心断言

1. 每个模拟步都验证 `区内剩余有机资源 + 运输中货物 + 已卸货累计 = 8.250`，容差为 0.00001；货舱不出现负数。
2. 玩家资源只在实际卸货后增长，且发生入账时，单位必须已自然到达真实兵营的允许到达范围内。
3. 三次卸货分别为 3.000、3.000、2.250；区内合格资源正常耗尽并失活，尾批不会永远困在不足满载的货舱中。
4. 持续采区在卸货后仍然存在，第二次卸货后无须重新下令即可再次出发；采区耗尽后的观察期没有重复卸货或免费收益。
5. 区内错误资源类型和区外资源在整个路线中都保持不变。累计被动吸收为零，所以测试收入确实来自运输。
6. 手动地面移动会替换持续采区，抵达后进入原地待命；自动采集不能抢回控制权。玩家明确重新指定采区后才恢复采集，**不是手动任务结束后自动恢复旧采区**。

## 复现

在项目目录执行：

```sh
/home/ubuntu/fungi/tools/godot/4.7/godot --headless --path . --script res://tests/chapter1_economy_cycle_smoke.gd
```

成功输出包含 `CHAPTER1_ECONOMY_CYCLE_SNAPSHOT` 和 `CHAPTER1_ECONOMY_CYCLE_OK`，退出码为 0。测试关闭自动存档，成功结束时释放场景并等待一帧后退出，不需要图形界面或开发者资源。

## 仍未覆盖的边界

- 本测试没有把普通开局、建造兵营、返巢循环连成同一条完整成长路线，也没有证明 3 天第一章的经济平衡或真人操作易用性。
- 没有在多兵营、多单位争抢、矿物专职采集、敌人攻击、负伤修复、母体死亡或菌丝断连情况下验证同一循环。
- 没有在运输中途插入存档读取或 48 小时离线结算；这些已有独立回归，本文件不将它们当作本路线已经验证的结果。
- 没有验证资源后来补充时的重新开工、自动恢复被手动命令取代的旧任务，也不承诺跨章节自动继承采区。
- 没有修改单位价格、容量、吸收速度、移动速度或生产逻辑。视觉表现与长时真实地图体验仍需另行测试。
