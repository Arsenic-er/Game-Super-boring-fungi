# 首个独立任务：场景内状态与下一步提示

日期：2026-10-03。范围仅为既有 FirstSupply 首任务的界面收尾，不制作第二任务，不改变任务时长、资源价格、材料奖励或存档格式。

## 目标

原任务框在大窗口显示标题和三项进度，在 640×360 小窗口仅显示标题。达标后必须主动打开主巢面板才能知道可以结算。此次把完成状态和下一步操作放在场景内，仍复用 J 与现有入口。

- 提示依据当前真实吸收量、成熟存活菌丝和菌落状态，不能依靠曾经达标的缓存。
- 完成时明确提示打开结算；有效菌丝下降后立即恢复未完成提示。
- 只读展示，不自动弹窗、返巢、保存、发放材料、花费资源或推进模拟。
- 七语言；既有大小窗口布局都要保留可读的任务状态。
- 数字显示与原有目标容差共用规则，避免判胜与显示相互矛盾。
