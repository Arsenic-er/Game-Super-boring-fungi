# 培养基争夺 · substrate_race

用途：审查“抢占资源区”与“实际得到补给”的双重目标，以及原地繁殖的细菌是否构成可理解的资源竞争。

## 初始条件

地图种子 **8221**。一个普通核心，有机 220.000、矿物 24.000、DNA 0、水无限；研究、强化和建设分支为 0，无兵营或军队。主巢入口等级 3，出征不继承等级加成。两处争夺区各有 **5** 个初始细菌，随后可自行吸收和分裂。通用规则见[索引](README.md)。

## 完成与失败

| 条件 | 目标 | 计数逻辑 |
| --- | ---: | --- |
| 接入争夺区 | 2 处 | 成熟、非孤立、由存活核心支持的菌丝线段进入目标中心 75 世界单位内 |
| 实际吸收有机 | 440.000 | 本任务累计吸收，不看当前库存 |
| 实际吸收矿物 | 20.000 | 本任务累计吸收，不含开局库存 |

两处中心为世界坐标 **(520, -180)**、**(520, 210)**。以上条件同时达成且己方仍有存活核心才可结算。全体己方核心死亡失败；细菌仍存活、己方没有杀敌或某处资源减少，都不会单独判败。

## 可尝试的玩法

先稳定起步补给，再观察两处标记与菌丝延伸路径。可以分两路经营，也可以先保证一处再接入另一处。基础腐生扩张可完成任务，不强制通过杀光细菌占领；若选择额外食性，应与扩张投入比较成本。

## 验收清单

- [ ] 初始恰有两组各五个细菌；正常等待能看到真实吸收与繁殖，不要求其移动巡逻。
- [ ] 两处任务轮廓可读，但情报标记不能把黑幕后所有资源、细菌一起显露。
- [ ] 只派部队经过、只把光标移入、菌丝仍在生长时，都不能计作成熟接入。
- [ ] 一条成熟有效菌丝进入相应半径后该区域计入；不能把同一区域算两次。
- [ ] 失去有效存活连接后区域占用应重新计算，而不是永久保留占领勾选。
- [ ] 接入两区但吸收目标未满不能胜利；初始矿物 24 不直接满足目标 20。
- [ ] 不击杀细菌的正常付费扩张路线应可通关；不能偷偷强制食性或兵种门槛。
- [ ] 保存／读取后细菌数量、资源余量和有效连接判断不被重置。

## 设计边界与证据

“接入”当前按成熟菌丝线段与区域的距离判定，不要求驻军、建核心或消灭区域全部细菌。这是资源竞争关，不是新增领土占领系统。
