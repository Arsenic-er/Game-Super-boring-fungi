# 双线压力 · two_fronts

用途：审查同时处理两侧敌人和战时补给，尤其确认额外经营目标不会被进入挑战前的历史收入直接满足。

## 初始条件

固定家园种子 **0xF00D47**；一个已展开普通主核，有机 220.000、矿物 24.000、DNA 0、水无限。主巢 **3 级**，保留载量 +10% 与核心回复 +10%；研究、核心强化、三条建设分支均为 0，无预制兵营或军队。正常资源与细菌保留，旧敌方真菌与旧生态事件清除。详见[切片基线](README.md)。

## 完成与失败

手动开启并完成 **3 波**，规模为 **4／5／6**，合计真实击败 **15** 名来袭者。同时从**进入挑战时**起新增实际吸收有机 **60.000**、矿物 **2.000**；整备期的真实吸收可以计入，不需要等第一波才开始算。三项条件与至少一个己方核心存活同时满足才可结算。

敌人每名初始生物量 **1.700**，速度 **9 世界单位／模拟秒**，攻击率 **0.022 生物量／模拟秒**。每波按单位交替从东西两侧出现，参考当前两端最外侧存活核心。不是“先全部东边、下一波全部西边”。全体己方核心死亡失败。

## 可尝试的玩法

规划有机与矿物的持续供给，正常建兵营和防守部队，再手动开波。比较分兵守两侧、集中兵力机动和调整外侧核心位置的差别。可以在波间整备；高级兵种不是必选项。

## 验收清单

- [ ] 开局无波次自动触发；己方扩张和整备仍要正常付费。
- [ ] 每波都从两侧实际产生敌人，数量总计 4、5、6，与面板一致。
- [ ] 当前波未结束时不能重复开波；完成一波也不自动开启下一波。
- [ ] 初始库存或挑战前家园历史收入不满足新增吸收；挑战整备期真实吸收可以增加进度。
- [ ] 三波已击退但有机或矿物未达标时不能提前胜利。
- [ ] 仅消除一个方向敌人不算全波完成，真实死亡记账需覆盖全部出生数量。
- [ ] 波中保存／读取后两侧剩余敌人、波次与吸收基线一致，没有双倍收入。
- [ ] 获胜、失败或撤退均恢复进入挑战前家园，不能把临时库存或兵力带回套利。

## 设计边界与证据

目标资源是菌落实际吸收的增量，不是孢子卸货量。没有“矿物仓库必须始终大于 2”要求；采到后正常消费不会倒扣累计吸收。主巢等级回复加成并不代表开局赠送研究或免费治疗。
