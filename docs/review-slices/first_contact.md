# 第一次接触 · first_contact

用途：审查第一次主巢防守的准备、开波、攻击指令与波次反馈，确认敌人不会在玩家准备前自动袭来。

## 初始条件

本切片使用固定 **0xF00D47** 家园种子，一个已展开普通主核；有机 220.000、矿物 24.000、DNA 0、水无限。主巢 2 级，保留等级固有的载量 +10%；研究、核心强化、三条建设分支均为 0。无预制兵营或军队，仅普通游猎孢子许可。正常家园资源和细菌保留，挑战初始化清除旧竞争真菌与旧生态事件。详见[切片基线](README.md)。

## 完成与失败

由玩家主动开启 **3 波**来袭，分别 **2／3／4** 名，总计 **9** 名。必须真实击败全部来袭孢子并保住至少一个己方核心；不要求额外采集量或菌丝长度。

每名来袭者生物量 **1.200**，移动速度 **8 世界单位／模拟秒**，攻击率 **0.018 生物量／模拟秒**。波次从东、西、东侧出现，位置参考当前己方最外侧存活核心，不是永远固定在屏幕某一点。敌人接近部队时可攻击部队，否则追击己方核心。所有己方核心死亡失败。

## 可尝试的玩法

先正常经营、生产 DNA、建兵营和部队；准备好后在任务面板手动开第一波。尝试集中防守、提前拦截或有损撤回维修。波间允许整备，后一波不应抢先自动开始。

## 验收清单

- [ ] 初始无来袭者；无论等待多久，未按开波都不自动出生敌人或判胜。
- [ ] 每次只开启当前一波，战斗中重复点按钮不能叠加额外波次。
- [ ] 三波实际数量为 2、3、4，当前来袭方向和实际出现侧一致。
- [ ] 右键点到重叠在己方兵营上的敌人仍能攻击敌人，不被错误解释为返航。
- [ ] 敌人造成连续小数伤害，己方可以通过正常攻击击败它们。
- [ ] 必须发生真实死亡记账；敌人因读取错误消失不能被当作胜利。
- [ ] 波中保存／读取保持存活敌人的位置、生物量、目标与剩余波次，不重复刷兵。
- [ ] 输掉、撤退或获胜返回时恢复切片战前家园；只有符合条件的首胜奖励回流。

## 设计边界与证据

正式战役会继承玩家实际建成的主巢；这里从基础家园付费整备，不能拿额外建设时间直接代表正式战役时长。普通游猎孢子即可完成，不强制专属食性或高级战斗兵种。
