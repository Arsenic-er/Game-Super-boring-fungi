# 远端粮仓 · remote_pantry

用途：审查兵营、资源采集兵种、猎区命令及实际搬运返库的闭环，尤其确认“找到资源”和“把资源带回来”不会混为一谈。

## 初始条件

有机 220.000，矿物 24.000，DNA 0，水无限；一个普通核心，无预制兵营或军队，研究／核心强化／建设分支均为 0。主巢入口等级 2，但出征不享受主巢等级加成。仅普通游猎孢子已有许可；矿物采集兵种需正常解锁。地图种子 **0xCA472**。通用规则见[索引](README.md)。

## 完成与失败

至少一个己方核心存活，并由孢子真实卸货返库累计达到：

| 货物 | 目标 | 不计入的内容 |
| --- | ---: | --- |
| 有机营养 | 36.000 | 初始库存、菌丝被动吸收、还在孢子身上的货物 |
| 矿物 | 4.000 | 初始库存、菌丝被动吸收、尚未卸载的矿物 |

全体己方核心死亡失败。没有额外时间限制，也没有要求所有采集孢子无伤返回。

## 可尝试的玩法

先建立能持续供养核心的菌丝，正常生产 DNA、建兵营。选择普通游猎孢子搬有机营养，再用正常商店解锁适合矿物的采集兵种。把猎区放在部队可运营范围内，观察它们采集、满载返程与卸货；可以调整中继布局或编队分工，不规定唯一解法。

## 验收清单

- [ ] 菌丝自然吸收可以增加库存，但返库目标不因此自动上涨。
- [ ] 制造 DNA、建设兵营、解锁兵种和排产都按正常价格扣除资源。
- [ ] 生产菜单展示兵种与成本，Shift／Ctrl 批量数和成本对应变化，不能免费批产。
- [ ] 能用选中单位与猎区命令设定有效采集区域；单位不能因指令失效一直无提示停住。
- [ ] 携货途中目标不提前完成；回到母体卸货后计数才上涨。
- [ ] 只有有机返库达标、矿物未达标时不能胜利。
- [ ] 保存／读取后货物、目标累计量和队列不丢失、不重复卸货。
- [ ] 正常达到两项后可结算；重复结算不再次发首胜材料。

## 设计边界与证据

这是后勤运输关，不强制细菌或真菌食性。目标不是把整个资源点搬空，也不是采集兵种都天生能采矿。自动路线曾用三名普通游猎孢子与一名正常解锁的矿物采集者通关；这只是可行性证据，不是推荐的唯一编队。
