# 稳定菌落 · stable_colony

用途：审查第一章最终挑战是否同时考验防守、补给和菌丝建设，并在真实完成后明确结束本章，而非仅“等够时间”。

## 初始条件

固定家园种子 **0xF00D47**，一个展开后的普通主核。有机 220.000、矿物 24.000、DNA 0、水无限；主巢 **4 级**，保留载量 +10%、核心回复 +10%、对敌方真菌核心／守卫伤害 +10%。研究、核心强化、三个建设分支均为 0，无兵营或军队；正常家园资源与细菌保留，旧敌方真菌和旧生态事件清除。详见[切片基线](README.md)。

## 完成与失败

以下全部达成，且至少一个己方核心存活：

| 条件 | 目标 | 计数规则 |
| --- | ---: | --- |
| 完成手动波次 | 4 波 | 规模 4／6／7／8 |
| 真实击败来袭者 | 25 名 | 需匹配已出生总数的实际死亡 |
| 挑战新增有机吸收 | 120.000 | 自进入挑战起累计；准备期也算 |
| 挑战新增矿物吸收 | 4.000 | 同上，初始库存不算 |
| 成熟存活菌丝 | 300 μm | 当前有效网络，共 600 世界单位 |

敌人每名生物量 **2.100**，速度 **10 世界单位／模拟秒**，攻击率 **0.026 生物量／模拟秒**。每波从东西两侧出现，参考当前最外侧存活核心。每波都由玩家主动开始。所有己方核心死亡失败。

## 可尝试的玩法

从基础家园付费整备，建立能长久工作的有机与矿物供给，扩展成熟网络，再按自己的承受能力手动开波。比较保护外侧核心、分区防守和集中机动的效果；波间可修复补充，但仍正常消耗资源。

## 验收清单

- [ ] 四波人数准确，未开波不会生成敌人；未结束当前波不能叠开下一波。
- [ ] 4／6／7／8 的真实死亡累计为 25；敌人消失或出存档范围不能代替击败。
- [ ] 整备期实际吸收可计入 120／4，但初始库存和进入前历史收入不计。
- [ ] 未成熟、孤立、归属死亡核心的菌丝不算完整网络；300 μm 以当前有效网络判定。
- [ ] 打完所有敌人但经营目标任一不足时不能结算；不能只靠战斗计时通关。
- [ ] 完成前三波并保存／读取后第四波仍可正常开启，不重刷前三波或重复记账。
- [ ] 胜利结算显示第一章完成；前置“已完成”是切片入口准备，不能误称你已人工审查八关。
- [ ] 任意结果都恢复战前基础家园；首胜材料只发一次，不带回临时生产的军队或库存。

## 设计边界与证据

网络要求是结算时现存成熟长度，不要求全在最后一波新建。正式战役允许继承成熟主巢，本切片从基础家园起步多出的整备时间不能直接当作终章设计时长。第一章结束后能继续经营，但后续宏观章节尚未制作。
