# 污染前缘 · toxic_frontier

用途：审查可预警的毒素环境、采集路径选择与真实返库，确保危险能被理解和规避，而不是随机强迫扣血。

## 初始条件

地图种子 **8223**。一个普通核心，有机 220.000、矿物 24.000、DNA 0、水无限。主巢入口等级 4，出征不享等级加成；所有研究、强化与分支为 0，无预制兵营或军队，只有普通游猎孢子初始许可。通用规则见[索引](README.md)。

## 完成与失败

三个条件同时成立，且仍有己方存活核心：

| 条件 | 目标 | 实际含义 |
| --- | ---: | --- |
| 有机真实返库 | 48.000 | 孢子卸下的货物累计，不是初始库存或被动吸收 |
| 矿物真实返库 | 6.000 | 同上 |
| 不同搬运者成功返库 | 2 名 | 不同单位 ID，确实携货并在母体附近卸货；空跑不算 |

同一孢子来回两次不等于两名；它成功卸货后再受伤／死亡，不会擦除已经证明的返库事件。“安全返库”指当时存活、未失联并完成卸货，不要求全程无伤，也不要求两个都永远存活。全体己方核心死亡失败。

危险循环：最初等待 **180 模拟秒**，在 **(530, -100)**、半径 **125 世界单位**的区域预警 **60 秒**，之后毒素激活 **240 秒**；结束后重新等待 180 秒。地图南侧有可绕行空间。

## 可尝试的玩法

建立有机／矿物来源、兵营和至少两名搬运者，观察预警区域再安排猎区与返航路径。可以避开北侧污染圈从南侧经营，不强制购买特定抗性或食性。测试受伤返航与维修的反馈是否清楚。

## 验收清单

- [ ] 毒素先预警再激活，时间和地图范围可读；刚出现预警不能无提示当作持续激活。
- [ ] 南侧绕行可用；不能存在不显示的 x 坐标资格线限制有效搬运。
- [ ] 菌丝被动吸收、空载侦察和仅进入毒圈均不增加“返库”目标。
- [ ] 一名单位多次运输不能算两名；两名不同单位真实卸货后可达到人数目标。
- [ ] 在运输中或离母体很远时货物减少，不能被误认作合法卸货返库。
- [ ] 任意一个货运总量不足或人数仍为一名时，不能胜利。
- [ ] 预警期／激活期保存再读取，剩余时长、货物及已经返库的单位身份持续一致。
- [ ] 长时间生产替补单位后仍可正常保存，不因历史搬运者 ID 无限累积而损坏存档。

## 设计边界与证据

当前只做有预警的毒素事件，不增加温度、酸碱或气候系统。目标没有要求必须穿越毒圈、击杀敌人或使用特定兵种；危险路径本身不是获取返库资格的隐藏条件。倍速会同步加快环境循环。
