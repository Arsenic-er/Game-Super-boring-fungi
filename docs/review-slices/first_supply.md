# 第一条补给线 · first_supply

用途：审查最基础的“伸长菌丝—长出细菌丝—缓慢吸收—继续扩张”是否容易理解。这里没有强制战斗、预制兵营或倒计时胜利。

## 初始条件

有机 220.000，矿物 24.000，DNA 0，水无限；一个位于原点的健康普通核心，研究／核心强化／建设分支均为 0。主巢入口等级 1；没有预制军队。地图种子 **0xCA471**，资源来自场景中四个聚集区；没有初始细菌和竞争真菌。通用隔离规则见[索引](README.md)。

## 完成与失败

三个条件必须同时成立，且至少一个己方核心存活：

| 条件 | 目标 | 实际计数 |
| --- | ---: | --- |
| 吸收有机营养 | 360.000 | 本任务累计实际吸收，不是当前库存 |
| 吸收矿物 | 18.000 | 本任务累计实际吸收，不包含初始 24 矿物 |
| 成熟存活菌丝 | 300 μm | 600 世界单位；按当前成熟且有存活核心支持的网络计算 |

所有己方核心死亡触发失败。没有额外的强制时间限制；营养花光但仍有补给不等于失败。

## 可尝试的玩法

观察资源聚集区，再决定向哪些方向付费延伸。等待主干成熟与细菌丝逐步吸收，比较向多方向铺设和集中开发一处的反馈。DNA 与升级可选，不要求照抄某条施工顺序。

## 验收清单

- [ ] 开局资源符合上表，但三个目标仍未达成；初始库存不直接完成吸收目标。
- [ ] 延伸消耗营养，主干有生长过程；不是点击即生成完整吸收收益。
- [ ] 有机和矿物细菌丝均能连接并慢慢吸收，资源点随进度变暗，不应瞬间清空。
- [ ] 延伸预览时右键取消，不付费、不额外留下菌丝。
- [ ] 只有两项达标时不能结算；新增菌丝未成熟时不能提前计入成熟长度。
- [ ] 菌丝失去存活核心支持后，不应一直算作健康成熟网络。
- [ ] 中途保存后重开本关，库存、资源余量、菌丝与累计吸收应保持一致。
- [ ] 全部己方核心死亡不能领取胜利；正常首次胜利只能领取一次材料。

## 设计边界与证据

这是经营入门，不测试采集孢子的货运量；库存降低不意味着目标倒退。目标中的“吸收”与后续粮仓的“返库”不是同一指标。
