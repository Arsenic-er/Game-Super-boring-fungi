# 第一章：任意进度切入与九个独立离线审查切片

**无需从头玩：打开“00 主巢分支审查.cmd”，选择进度节点，再新开或继续。** 游玩中 **F8** 随时暂停审查、保存或切换节点，主巢按 **J** 选择分支任务。每个节点可以完整出征、返巢、升级、再出征。

直接打开 FungiMicroculture.exe 仍是正式游戏。01–09 CMD 保留原来的孤立单关审查；它们不开放其他支线。

启动参数是 `-- --audit-hub`，可选 `--audit-stage=<节点ID>` 与 `--audit-lang=<语言>`；默认中文启动器打开节点选择界面。七种语言与原切片一致。每节点存档、设置、报告位于 `user://campaign-audit-v1/<节点ID>/`；正式档、开发者档、九个单关档均不共用。无离线收益，无开发者免成本模式。

选节点不会自动覆盖它的旧档。“新开”采用下述合成预设；已有档可继续，重置需再次确认。F8 面板打开时模拟暂停，切换前先保存当前已开始的进度；保存失败不切换。关闭面板可回到正在玩的场景，包括尚未结算的出征。

所有主巢流程节点提供相同的**预制审查家园**：一个展开后的普通主核、一个兵营、四条各 120 μm 的成熟菌丝、八只普通游猎孢子、220 有机营养/24 矿物/0 DNA；研究与可选专长均为 0，地图保留正常资源和细菌。这不是原九个单关采用的无预制军队开荒基线，也不是正常付费开荒的证明；准备结束后的费用、战斗和奖励都走正常规则。

各节点前置进度按“第一条补给线 → 升 2 级 → 远端粮仓 → 失联网络 → 第一次接触 → 升 3 级 → 污染前缘 → 双线压力 → 升 4 级 → 稳定菌落”截取，材料和专属组织通过真实战役账本结算，不任意赋值。培养基争夺与边界反攻未完成，始终保留补玩空间。**合成前置完成记录只用于跳过前置，不是玩家成绩或任务验收证据。** 审查报告标明预设、初始条件、构建和操作后的实际状态。

## 九个单关切片

这套切片用来逐关审查已实现的玩法，不是九份互相复制的完整游戏，也不是自动通关录像。所有入口共用一份 Windows EXE 与 PCK；每关使用自己的存档，免打前置关卡。关内采集、建造、生产、攻击、伤亡和胜负仍走正常游戏逻辑。

## 正常游戏的分支循环

- 第一条补给线首胜、主巢升至 2 级：远端粮仓、失联网络、培养基争夺同时开放；任选两张不同地图首胜，即可开启第一次接触。
- 第一次接触首胜、主巢升至 3 级：污染前缘、边界反攻同时开放；任选一张首胜，即可开启双线压力。
- 双线压力首胜、主巢升至 4 级：开启稳定菌落。未选分支保留可选，通关后仍可补做；已完成任务可以重玩。
- 专长建设不属于挑战门槛。初级分支首胜即可获得对应组织、购买可选第 1 级专长；每级消耗对应组织 1 份，第 2 级需要主巢 3 级。专长每级 +15%，也带入独立外出；主巢等级的各项 +10% 被动仍只在主巢和挑战中生效。

以下编号仅是沿用九个 CMD 的审查顺序，不是上述正常游戏的强制通关顺序。入口名称与隔离存档约定不变。

## 切片基线：先看这里

- 初始有机营养 **220.000**、矿物 **24.000**、DNA **0**；培养皿水分无限。
- 不启用开发者模式，不免费建造、瞬间生产、补兵、补血或伪造目标计数。研究等级、核心强化、主巢建设分支均从零开始。
- 最初仅有普通游猎孢子的生产许可；没有预制兵营或军队。其他兵种仍需正常解锁，专属兵种仍受对应食性约束。
- 六个出征任务不享受主巢等级能力加成。各自有独立场景、固定地图种子；失联网络另外包含两处死亡遗迹与一处活的受损中继。
- 三个挑战切片使用固定种子 **0xF00D47** 的基础家园，完成正式主孢子展开后只有一个普通主核；地图保留正常家园的资源和细菌，不是空白背景。挑战开始清除旧敌方真菌、守卫和旧生态事件；来袭波次另由挑战控制。
- 挑战的主巢等级按其最低条件设置：第一次接触 2 级，双线压力 3 级，稳定菌落 4 级。因此保留正常等级加成：2 级载量 +10%，3 级另加核心回复 +10%，4 级另加对敌方真菌核心／守卫伤害 +10%；三个可选建设分支仍为 0。
- 为直接进入指定关卡，切片会准备隔离的前置完成状态。**这只是跳关入口，不代表你已实际打完前置任务，也不构成这些任务的验收证据。**
- 正式战役的挑战继承玩家真实主巢；本套切片故意采用一致的基础家园，便于对照关卡本身。不能据此推断成熟主巢在正式战役中的难度。

## 入口与存档约定

审查入口使用 EXE 的用户参数 `-- --review-mission=<任务 ID>`，由游戏内部切换到独立场景 `ReviewSlice.tscn`，不使用发行版禁用的场景覆盖参数。语言参数为 `--review-lang=zh_CN`；其余支持 `zh_TW`、`en`、`ja`、`es`、`de`、`ru`。请优先使用交付目录内对应的 Windows 启动入口，不需要安装 Godot 或联网加载网页。

各关隔离目录为 `user://review-v1/<任务 ID>/`，其中 `save.json` 是本关存档，`settings.json` 是本关设置，`report.json` 是审查报告。这里的 `user://` 是 Godot 用户数据目录，不是 EXE 所在目录；不要删除正式游戏存档来重开切片。

初次进入停在审查面板，尚未开始操作时不会消耗关卡时间；已有存档不会被启动动作覆盖。审查工具不改变正常目标和价格。

1. 在交付文件夹双击对应中文关卡的 `.cmd` 入口。第一次选“新开 / 重置本关”，再选“返回试玩”；已有进度选“继续本关存档”。入口直接启动游戏，不依赖 PowerShell 或改变系统脚本策略。
2. 试玩时按 **F8** 返回暂停的审查面板，可保存、读取、选择 **1／5／20 倍速**或导出报告。已有进度的重置需要再次确认。
3. 开局审查面板优先显示本关任务清单；游玩时右侧逐条显示实际进度和下一步提示。按 **J** 查看详细目标、开启波次或结算；按 **Esc** 查看原游戏操作指引和设置。倍率不免除成本，F8 面板打开时不推进模拟。第一关的清单是吸收有机 360、矿物 18、成熟存活菌丝 300 μm，不附加旧家园教学里的兵营、DNA 或击败菌落要求。
4. 发现问题时导出本关报告，并记录操作顺序。报告保留当前构建、开局构建来源、初始快照指纹、所用倍率和目标统计；它不是自动证明玩法合格的评分器。

切片离线期间不增长资源，不计算正式主巢的 48 小时离线收益。胜利、撤退或失败后，点击“返回主巢”会回到本切片自己的可操作主巢，而不是菜单；可以继续经营、保存、读取或用 F8 暂停审查。任务结果仍被保留，主巢变化不会改写该任务成绩。切片不开放其他关卡；重打本关需在 F8 明确重置，审查下一关则使用它自己的中文启动入口。源码相对路径用于与服务器/Git 仓库对照，离线测试包只包含程序、资源与审查说明，不包含开发环境。

## 审查方式

先用 1 倍速判断节奏、读图、提示和操作，再使用加速检查长流程。加速运行的现实时间不能当作正常首通时间。建议每关至少做一次正常胜利、一次中途保存／读取，并选择一个明确的失败条件验证。

每张审查卡分开列出“应当发生的事”和“不应当发生的事”。复现问题时记录任务 ID、操作顺序、实际／期望结果，以及该关的报告文件；请勿把正常游戏存档混入切片目录。

- 期望结果：

- 存读档是否保持任务阶段：

## 奖励与设计边界

每关首次正常胜利可按正式逻辑产生 3 份通用主巢材料及下表对应专属组织；重复胜利、失败、撤退不发奖励。通用材料仅用于主巢升级，专属组织仅用于对应专长，不互相占用。未列出的任务不发组织。

| 首胜任务 | 运输组织 | 韧性组织 | 防御组织 |
| --- | ---: | ---: | ---: |
| 远端粮仓 | 1 | 0 | 0 |
| 失联网络 | 0 | 1 | 0 |
| 培养基争夺 | 0 | 0 | 1 |
| 第一次接触 | 1 | 1 | 1 |
| 污染前缘 | 1 | 1 | 0 |
| 边界反攻 | 0 | 1 | 1 |

切片奖励只存在于对应隔离档，不汇入其他关卡或正式主巢。切片为跳关设置的前置完成标记不是实际首胜，不作为额外领奖证据。挑战结果恢复战前家园，只保留符合条件的首胜奖励；挑战内库存和军队不会永久带回。

正常战役的 CampaignState 从 V1 一次性迁移至 V2：保留旧已完成/已开放任务及合法进行中的任务，保留专长等级，退还旧专长花费的通用材料，并按已完成任务奖励减去保留等级结算新组织余额。既有权限保留不伪造首胜、不重复领奖，不迫使旧档补打新前置；新档遵守三选二/二选一。切片目录名 review-v1 不因战役账本升级而改名。

这些切片针对实验室第一章，不包含后续细胞、生物、人类社会或世界地图。4–6 小时主动首通是待人类试玩验证的整章设计目标。脚本能通关、截图能渲染都不能代替你的节奏和操作审查；测试文件中的修改计数器等边界夹具也不是正常玩家路线。

现有正常付费路线及其原记录时长保留作基线；这些旧数据不是本次分支、专长外出效果或完整战役节奏的新验收结果。本轮最终回归与构建结论见开发日志。

源数据优先级：本关 `.tscn` 与世界脚本 → 切片基线与隔离逻辑 → 本目录审查卡。关卡数值有修改时应同步更新卡片，不能只改文字掩盖实现差异。各卡片的场景、脚本与测试相对链接面向完整源码仓库；离线试玩包不必携带整份源码，可据路径回到源码库核对。
