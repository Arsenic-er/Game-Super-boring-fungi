# 主巢与独立任务的开发者测试入口

更新：2026-10-04。九项独立场景已实现，主巢上限四级；当前规则见 [第一章清单](CHAPTER1_APPROVED_MISSIONS.zh-CN.md)。下方“验证”保留 2026-10-03 原始记录，新一轮验收见开发日志。

## 怎么使用

进入独立开发档后，按 F10 打开开发者工具，翻到第四页“主巢与任务”。既有开发档新局会自动萌发；如果测试中手动恢复了游动主孢子状态，须先萌发才能出征或调整主巢。

- 主巢等级 ±1：在现有 1–4 级之间调整，不消耗筑巢材料。
- 升级材料 ±1：0–27 份安全上限，界面读取实际常量；这不是新存档赠送或正式升级价格。普通玩法九关首胜合计最多产出 27。
- 出征首次补给：进入真实的 FirstSupply 独立场景，仍使用既有固定补给、目标和保存事务。
- 返回主巢：只打开原有撤退确认面板，确认后才丢弃临时任务世界并无奖励返回；可以取消。不会直接发放胜利材料。

页面显示当前世界、主巢等级和材料余额。到达上下限或处于不允许的状态时，按钮变暗；鼠标移上去显示原因。任务期间不能修改存放在主巢的等级和材料。首次胜利结算仍从原主巢面板执行。

第四页快捷出征仍进入首关；其余关卡通过 J 面板的左右翻页选择。调高主巢不会伪造后续任务完成，所以后续剧情前置仍须完成真实任务。调级不会发放任务材料，降级也不重置首胜记录。

## 保存与隔离

四个参数调整按钮会立即保存到精确的独立开发存档路径，只有开发模式标志和开发路径同时正确才允许执行。普通档、开发快照路径或其他临时路径不能借此写入主巢参数。

修改采用复制、限定字段调整、沿用现有状态校验、保存的顺序；保存失败恢复之前的战役账目。保留主巢身份、尝试编号、首胜标记和上次结算记录，不清空整个战役。

将主巢设为二级会遵循既有存档规则：二级意味着首任务已完成。再降回一级不会重置首胜奖励资格，避免调级操作意外重复发奖。材料调节是显式开发工具，不伪装成普通任务奖励。

出征失败会保留原主巢场景、运行时、磁盘记录和开发页。返巢沿用撤退确认与复合存档事务；六个外出任务允许最多 48 小时主巢离线结算，三个主巢挑战不重复计算该收益。开发按钮不绕过规则，也不自动完成任务目标。
