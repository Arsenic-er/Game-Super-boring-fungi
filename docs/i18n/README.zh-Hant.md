# 《超級無聊真菌遊戲》

一款從微觀孢子出發，逐步擴張至生態系統、人類社會、國家乃至整個地球的放置演化與征服遊戲。

目前版本為 Windows 早期原型 `0.44.0`，集中製作第一章「實驗室微型培養」。玩家只控制真菌，延伸菌絲、吸收營養、進化能力，並指揮能夠離開母體行動的遠征孢子。v0.40 加入了符合兵種職責的安全指令系統，避免單位執行不適合自身特性的採集或攻擊行動。

v0.41 會在全新安裝首次啟動時顯示七語選擇，並為資源 HUD、核心徑向動作、核心狀態與常用懸停提示、遠征狀態、細菌說明及 10 種兵種名稱提供簡體中文、繁體中文、英語、日語、西班牙語、德語與俄語；升級商店和長期目標正文尚未完成完整翻譯。

v0.42 已將全部 22 個長期目標、進化商店外殼、節點與生存升級、結構升級、通用兵營頁、兵營狀態面板下半部，以及三種特種兵的詳細說明擴充為七語。食性詳細頁、細菌組件、食性專屬單位頁、購買提示、兵營互動提示，以及章節引導、生態事件和競爭孢子雨文字仍待後續本地化。

v0.43 在 Esc 暫停選單加入六頁插圖玩法指引，以七種介面語言說明萌發菌絲、營養與 DNA、進化、兵營指揮、探索目標和菌落生存；每個主題旁都有獨立的粗像素插圖。
v0.44 完成食性詳細頁、細菌組件與食性專屬兵種頁面的七語化，並翻譯進化購買、解鎖及失敗回饋；西班牙語、德語和俄語等較長文字現在也會在像素 UI 控件內自動縮放。

## 下載與執行

前往倉庫的[最新 Release](https://github.com/Arsenic-er/Game-Super-boring-fungi/releases/latest)，下載 Windows ZIP，解壓縮後雙擊 `FungiMicroculture.exe`。

- 平台：Windows 10/11，64 位元
- 安裝：無需安裝，遊戲資料已內嵌於 EXE
- 存檔：保存在目前 Windows 使用者的應用程式資料目錄
- 因測試版本尚未進行程式碼簽章，Windows 可能顯示 SmartScreen 警告

## 核心玩法

- 在可大範圍縮放的實驗室培養環境中探索有機營養、礦物離子、細菌群落、競爭真菌與永久探索黑幕。
- 從單一孢子核心萌發，延伸主菌絲並自動長出細吸收菌絲，以緩慢的小數速率累積資源。
- 消耗營養製造 DNA，購買可逆進化、結構、生存、環境適應與食性升級，並完成具有不同獎勵的長期目標。
- 管理核心與遠征孢子的三位小數生物量、毒素傷害、緩慢恢復、撤退修復，以及斷裂菌絲的衰亡與重新連接。
- 建造兵營核心，生產負責採集、運輸、礦物收集、偵察、抗菌戰鬥、對真菌戰鬥與區域部署的專門孢子。
- 為相容單位設定持久正方形防區、採集區或細菌清剿區；部隊會在返巢、修復、補員和有限離線結算後恢復任務。
- v0.40 的職責安全指令只允許相容兵種攻擊或採集目標；混編部隊中的不相容單位會移動至目標附近並原地警戒，指令回報會顯示執行、回退與不可用數量。
- 體驗細菌暴發、毒素區、競爭孢子雨、資源異常、戰爭黑幕、長期放置進度，以及具有多聲道音量控制的原創像素實驗室音效。

## 操作摘要

- 核心 DNA：普通點擊生產 1 點；按住 Shift 點擊生產 5 點；按住 Ctrl 點擊生產 10 點
- 左鍵：查看核心、選擇操作或選取遠征孢子
- 左鍵拖曳：以矩形框選部隊
- 右鍵：下達移動、採集、攻擊、斷絲或部署指令
- `Z`：設定正方形防區
- `X`：設定正方形採集區
- `V`：設定正方形細菌清剿區
- `C`：清除所選單位的手動或持久指令，健康單位將恢復符合自身職責的自動行動
- `R`：讓所選遠征孢子返回兵營
- 右鍵拖曳 / 中鍵拖曳：移動鏡頭
- 滑鼠滾輪：縮放
- `E`：開啟進化商店
- `G`：開啟長期目標
- `F5`：立即儲存
- `Esc`：關閉面板、取消操作或暫停／繼續

## 計畫中的尺度階段

微型培養只是遊戲的起點。未來將以獨立章節擴展至微生物與細胞、小型生物與物品、生態系統、人類社會、城市、國家和現代地球；較小尺度進化出的生理特徵將影響後續的傳播與征服策略。

## 開發

本專案使用 Godot `4.7` 與 GDScript。使用 Godot 開啟 `project.godot` 即可執行原始碼；自動化冒煙測試位於 `tests/`，Windows 匯出設定會將遊戲資料內嵌為單一 EXE。
