# 《超级无聊真菌游戏》

一款从微观孢子出发，逐步扩张至生态系统、人类社会、国家乃至整个地球的放置演化与征服游戏。

目前版本是 Windows 早期原型 `0.42.0`，集中制作第一章“实验室微型培养”。玩家只控制真菌，延伸菌丝、吸收营养、进化能力，并指挥能够离开母体行动的远征孢子。v0.40 加入了符合兵种职责的安全指令系统，避免单位执行不适合自身特性的采集或攻击行动。

v0.41 在全新安装首次启动时显示七语选择，并为资源 HUD、核心径向动作、核心状态与常用悬停提示、远征状态、细菌说明及 10 种兵种名称提供简体中文、繁体中文、英语、日语、西班牙语、德语与俄语；升级商店和长期目标正文尚未完成全量翻译。

v0.42 已将全部 22 个长期目标、进化商店外壳、节点与生存升级、结构升级、通用兵营页、兵营状态面板下半区，以及三种特种兵的详细说明扩展为七语。食性详情、细菌组件、食性专属单位页面、购买提示、兵营交互提示，以及章节引导、生态事件和竞争孢子雨文案仍待后续本地化。

## 下载与运行

进入仓库的[最新 Release](https://github.com/Arsenic-er/Game-Super-boring-fungi/releases/latest)，下载 Windows ZIP，解压后双击 `FungiMicroculture.exe`。

- 平台：Windows 10/11，64 位
- 安装：无需安装，游戏数据已内嵌进 EXE
- 存档：单独保存在当前 Windows 用户的应用数据目录
- 因测试版本暂未进行代码签名，Windows 可能显示 SmartScreen 提示

## 核心玩法

- 在可大范围缩放的实验室培养环境中探索聚集分布的有机营养、矿物离子、细菌群落、竞争真菌与永久探索黑幕。
- 从单个孢子核心萌发，延伸主菌丝并自动长出细吸收菌丝，以缓慢的小数速率积累资源。
- 消耗营养制造 DNA，购买可逆进化、结构、生存、环境适应与食性升级，并完成奖励各不相同的长期目标。
- 管理核心与远征孢子的三位小数生物量、毒素伤害、缓慢恢复、撤退修复，以及断裂菌丝的衰亡与重新连接。
- 建造兵营核心，生产负责采集、运输、矿物收集、侦察、抗细菌战斗、对真菌战斗与区域部署的专门孢子。
- 为相容单位设置持久正方形防区、采集区或细菌清剿区；部队会在返巢、修复、补员和有限离线结算后恢复任务。
- v0.40 的职责安全指令只允许相容兵种攻击或采集目标；混编部队中的不相容单位会移动到目标附近并原地警戒，指令回执会显示执行、警戒回退与不可用数量。
- 体验细菌暴发、毒素区、竞争孢子雨、资源异常、战争黑幕、长期放置进度，以及具有多声道音量控制的原创像素实验室音效。

## 操作摘要

- 核心 DNA：普通点击生产 1 点；按住 Shift 点击生产 5 点；按住 Ctrl 点击生产 10 点
- 左键：查看核心、选择操作或选中远征孢子
- 左键拖动：以矩形框选部队
- 右键：下达移动、采集、攻击、断丝或部署指令
- `Z`：设置正方形防区
- `X`：设置正方形采集区
- `V`：设置正方形细菌清剿区
- `C`：清除所选单位的手动或持久指令，让健康单位恢复符合自身职责的自动行动
- `R`：让所选远征孢子返回兵营
- 右键拖动 / 中键拖动：移动镜头
- 鼠标滚轮：缩放
- `E`：打开进化商店
- `G`：打开长期目标
- `F5`：立即保存
- `Esc`：关闭面板、取消操作或暂停／继续

## 计划中的尺度阶段

微型培养只是游戏的起点。未来将以独立章节扩展到微生物与细胞、小型生物与物品、生态系统、人类社会、城市、国家和现代地球；较小尺度进化出的生理特征将影响后续的传播与征服策略。

## 开发

本项目使用 Godot `4.7` 与 GDScript。使用 Godot 打开 `project.godot` 即可运行源码；自动化冒烟测试位于 `tests/`，Windows 导出设置会将游戏数据内嵌为单一 EXE。
