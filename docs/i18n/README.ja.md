# Game: Super boring fungi

微小な胞子から始まり、生態系、人間社会、国家、そして地球全体へと広がっていく、放置型の進化・拡張ゲームです。

現在は Windows 向け早期プロトタイプ `0.47.0` を公開しており、第1章「実験室マイクロカルチャー」を開発しています。プレイヤーが操作するのは真菌だけです。菌糸を伸ばし、栄養を吸収し、能力を進化させ、母体の外で活動できる遠征胞子を指揮します。v0.40 では、各兵種が本来の役割から外れた採集や攻撃を行わない、役割制約付きの安全な指揮システムを追加しました。

v0.41 では、新規インストール後の初回起動時に7言語の選択画面を表示し、リソース HUD、コアの放射状アクション、コア状態と主要なホバーヒント、遠征状態、細菌の説明、全10兵種の名称を、簡体字中国語、繁体字中国語、英語、日本語、スペイン語、ドイツ語、ロシア語で表示できます。アップグレードショップと長期目標の本文は、まだ完全には翻訳されていません。

v0.42 では、22件すべての長期目標、進化ショップの外枠、ノードと生存進化、構造進化、汎用兵舎ページ、兵舎状態パネル下部、さらに3種類の特化兵種の詳細を7言語化しました。食性詳細、細菌コンポーネント、食性専用兵種ページ、購入通知、兵舎の操作通知、章ガイド、生態イベント、競争胞子雨の文言は今後の翻訳対象です。

v0.43 では Esc の一時停止メニューに、6ページのイラスト付き遊び方ガイドを追加しました。発芽、栄養と DNA、進化、兵舎指揮、探索と目標、コロニー生存を7言語で説明し、各テーマに専用の粗いピクセル絵を表示します。
v0.44 では、食性詳細、細菌コンポーネント、食性専用兵種ページを7言語化し、進化の購入・解放・失敗通知も翻訳しました。スペイン語、ドイツ語、ロシア語などの長いラベルは、ピクセル UI 内で自動縮小されます。
v0.45 では、第1章のリアルタイム案内、生態イベント、競争胞子雨の段階と報酬、敵菌警告カード、時間単位を7言語化しました。長いイベント表示と通知も狭い画面に収まります。
v0.46 では、第1章クリア報告、敵ユニットのホバー説明と戦闘通知、選択 HUD、指令結果、兵営の継続任務操作を7言語化しました。旧セーブの中国語撤退理由は安定 ID へ移行し、長い報告やホバー文字も狭い画面に収まります。
v0.47 では、セーブ読み込み時のオフライン進行を進捗表示付きのフレーム分割処理に変更しました。また、通常の進行から独立した開発者サンドボックスセーブを追加し、資源とアップグレードの無料化、段階制御、マップ上への資源、細菌、味方コア、兵舎、全10種の遠征胞子、敵対菌と守衛、生態イベントの配置に対応します。

## ダウンロードと起動

リポジトリの[最新 Release](https://github.com/Arsenic-er/Game-Super-boring-fungi/releases/latest)から Windows ZIP をダウンロードし、展開後に `FungiMicroculture.exe` をダブルクリックしてください。

- 対応環境：64ビット版 Windows 10/11
- インストール：不要。ゲームデータは EXE に内蔵されています
- セーブデータ：現在の Windows ユーザーのアプリケーションデータ領域に保存されます
- 趣味で制作している未署名ビルドのため、SmartScreen の警告が表示される場合があります

## 主なゲーム内容

- 大きくズームできる実験室環境で、有機栄養、無機イオン、細菌群集、競争真菌、探索によって開かれる暗闇を調査します。
- 1個の胞子核から発芽し、主菌糸と細い吸収菌糸を伸ばして、放置プレイ向けのゆっくりした小数単位の速度で資源を蓄えます。
- 栄養を消費して DNA を生産し、取り消し可能な進化、構造、生存、環境適応、栄養様式を強化し、報酬の異なる長期目標を達成します。
- 胞子核と遠征胞子の小数3桁のバイオマス、毒素ダメージ、緩やかな回復、撤退修理、切断菌糸の衰弱と再接続を管理します。
- 兵舎核を建設し、採集、輸送、無機物回収、偵察、対細菌戦、対真菌戦、範囲展開に特化した胞子を生産します。
- 対応する部隊に、永続する正方形の防衛・採集・細菌掃討エリアを設定できます。帰還、修理、補充、制限付きオフライン進行の後も任務を再開します。
- v0.40 の役割制約付き指揮では、適性のある兵種だけが対象を採集または攻撃します。混成部隊内の非対応兵種は目標付近へ移動して待機し、結果表示には実行・待機への切替・実行不能の数が示されます。
- 細菌ブルーム、毒素地帯、競争胞子雨、資源異常、戦場の霧、長時間の放置進行、チャンネル別音量調整に対応したオリジナルのピクセル実験室サウンドを体験できます。

## 操作概要

- 胞子核の DNA：通常クリックで1、Shiftを押しながらクリックで5、Ctrlを押しながらクリックで10生産
- 左クリック：胞子核の確認、操作の選択、遠征胞子の選択
- 左ドラッグ：長方形で部隊を範囲選択
- 右クリック：移動、採集、攻撃、菌糸切断、展開命令
- `Z`：正方形の防衛エリアを設定
- `X`：正方形の採集エリアを設定
- `V`：正方形の細菌掃討エリアを設定
- `C`：選択中の手動命令または永続任務を解除し、健全な部隊を役割に応じた自動行動へ戻す
- `R`：選択中の遠征胞子を兵舎へ帰還
- 右ドラッグ / 中ドラッグ：カメラ移動
- マウスホイール：ズーム
- `E`：進化ショップ
- `G`：長期目標
- `F5`：即時セーブ
- `Esc`：パネルを閉じる、操作を取り消す、ポーズ／再開

## 今後のスケール展開

マイクロカルチャーはゲームの出発点にすぎません。将来は独立した章として、微生物と細胞、小型生物と物体、生態系、人間社会、都市、国家、現代の地球へと進みます。小さなスケールで獲得した生理的特徴は、後の拡散・征服戦略に影響する予定です。

## 開発

本プロジェクトは Godot `4.7` と GDScript を使用しています。Godot で `project.godot` を開くとソースから実行できます。自動スモークテストは `tests/` にあり、Windows のエクスポート設定ではゲームデータを単一の EXE に内蔵します。
