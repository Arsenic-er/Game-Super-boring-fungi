第一章：九个独立游戏切片审查

先选你要体验的内容
- 完整“主巢选分支”循环：直接双击 FungiMicroculture.exe，进入正常游戏，
  在主巢按 J 选择任务。请用这个入口体验长期主巢、分支选择与阶段挑战。
- 孤立单关审查：双击对应中文关名 CMD。九个 CMD 不开放其他支线，
  不能据此体验或验收整章分支；文件编号只是审查顺序，不是强制主线。

正常游戏的分支与成长
- 第一条补给线首胜并升主巢 2 级，同时开放远端粮仓、失联网络、培养基争夺；
  任选两张不同地图首胜，开启第一次接触。专长购买不是必需条件。
- 第一次接触首胜并升主巢 3 级，同时开放污染前缘、边界反攻；
  任选一张首胜，开启双线压力。双线压力首胜并升主巢 4 级，开启稳定菌落。
- 未选分支保留可选，通关后也可补做。每关首胜给 3 通用材料，只用于主巢升级。
- 专属组织首胜奖励：粮仓给运输 1，失联给韧性 1，争夺给防御 1；
  第一次接触给三类各 1；污染给运输/韧性各 1，反攻给防御/韧性各 1。
- 专长每级消耗对应组织 1，最多两级；初级分支首胜后即可买第一级，
  第二级另需主巢 3 级。每级 +15% 专长也带入外出；主巢等级的 +10% 被动
  仍只在主巢/挑战生效。重复胜利、失败、撤退不给材料或组织。
- V1 旧存档一次迁移至 V2，保留合法旧进度、已经开放的任务与专长，
  退还旧专长通用材料支出并结算新组织；不补造首胜，不强迫补打新前置。
- 上述是本轮规则说明，不代表新分支平衡或真人首通节奏已完成验收。

运行方式
1. 保留本目录的 FungiMicroculture.exe 和 FungiMicroculture.pck。
2. 直接双击中文关名 CMD 文件，例如“01 第一条补给线.cmd”，无需创建快捷方式。
   入口无需 PowerShell 或 COM、不安装服务、不联网、不修改系统安全策略。
3. 九个入口直接进入指定关卡，无需前置通关；启动时命令窗口可能短暂闪现。
4. review-docs/index.html 是纯本地说明目录，只显示审查卡，不在网页运行游戏。
   每关 Markdown 原文亦保存在 review-docs，便于核对和记录反馈。
   审查卡中的源码路径供 Git 源码审计定位；本包不重复附带完整源码。

审查与正式战役的区别
- 每关独立存档，互不串档；正式游戏存档不会被审查切片覆盖。
- 存档、设置和审查报告分别位于当前 Windows 用户应用数据目录的
  游戏 user://review-v1/<关卡ID>/save.json、settings.json、report.json。
- 开局为明确的审查基线。出征关使用付费正常规则，不默认满级或无限资源。
- 三个主巢挑战使用预设主巢测试布局，并非从你的正式存档复制。
  它是可重复的测试条件，不代表真实战役中玩家一定拥有的资源和军队。
- 开局先看任务清单；进入游玩后右侧逐条显示目标进度和下一步提示，J 查看详情。
- F8 打开审查面板；基线、存档、重置以及结果以面板及对应审查卡为准。
- 返回主巢会进入本切片的可操作隔离主巢，不回菜单；可以继续经营和存读档。
  结算结果保留。重打需在 F8 重置；其他关卡使用各自中文入口，不能在本切片串关。
- 审查加速只加快模拟，不免除生产资源、科技成本、战斗伤害或任务条件。
  本切片禁用开发者免成本模式；测试加速也不作为普通玩家通关时长的证据。
- 胜败与进度以游戏内实际计数为准；审查结果不是“自动通过”。
- 再次打开同一关卡入口不会自动读取或覆盖进度；点击“继续本关存档”才读取。
  “新开 / 重置本关”只针对该关，已有进度需要再次确认；随后点击“返回试玩”开始。

反馈建议
先读该关审查卡的目标、初始资源、通过/失败条件和“需要人工确认”清单。
反馈请写关卡名、构建ID、是否重置、是否加速、具体操作和预期/实际结果。
build-info.json 记录源码提交、是否含未提交改动、源码内容哈希和打包时间，
以及各文件 SHA-256；审查面板读取相同构建标识，便于复现。

注意
正式战役与九个单关审查档互相隔离；完整分支体验请使用 EXE 正常游戏入口。
本包只有一份引擎和一份资源包，九个 CMD 入口不是九份重复游戏。
整体移动文件夹后仍可启动，但不要单独移动这些入口或 EXE/PCK 文件。
