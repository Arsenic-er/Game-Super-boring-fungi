《超级无聊真菌游戏》第一章独立审查包
作者：koko

直接切入“主巢选分支”审查，无需从头玩
双击“00 主巢分支审查.cmd”，选择八个进度节点之一，再新开或继续该节点。
游玩中随时按 F8 暂停、保存或切换节点；在主巢按 J 选择分支任务。
每个节点有独立存档，使用明确标注的合成前置进度和预制主巢；
可以完整出征、返巢、升级、再出征，之后仍正常付费和战斗。
直接打开 FungiMicroculture.exe 仍是正式游戏；01–09 CMD 仍只审核孤立单关。
十个入口共用一份游戏，无需从头通关后才能审查后面的内容。
CMD 编号仅是审查顺序，不是强制主线；九个既有入口名称保持不变。

这是本地离线 Windows 游戏，不是网页试玩。只需下载一次；游戏本体无需联网。
请将全部文件保留在同一个文件夹，EXE 与 PCK 必须相邻。

只审查某一关：双击对应中文关名 CMD，例如“01 第一条补给线.cmd”。
九个入口解压后即可使用，无需安装、PowerShell、COM 或创建快捷方式。
启动时命令窗口可能短暂闪现；它仅启动本地游戏，不修改系统安全策略。
完整说明见 START-HERE.txt；离线审查卡见 review-docs/index.html。

正式战役：首关后升主巢 2 级，初级三分支任选两张首胜，再开第一次接触；
随后升 3 级，高级两分支任选一张首胜，再开双线压力；升 4 级后开稳定菌落。
未选分支一直保留可选，专长建设不是通关门槛。每图仅首胜发 3 通用材料。
首胜组织：粮仓=运输1，失联=韧性1，争夺=防御1，第一次接触=三类各1，
污染=运输/韧性各1，反攻=防御/韧性各1；其他任务不发组织。
通用材料只升主巢；专长每级花对应组织1，最多两级，第2级需主巢3级。
初级分支首胜即可选购专长，每级15%也带入外出；等级10%被动仅主巢/挑战有效。
V1→V2 保留旧已开任务与合法进度，退还旧专长通用材料支出、结算新组织，
不补造首胜或强迫补打新前置。详情见 START-HERE.txt 和离线审查说明。
本说明不宣称新的分支平衡、真人体验或整章首通时长已经验收。
